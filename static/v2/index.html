DEVELOPER API

Call it from anywhere.

Every research function is available over HTTP. Integrate into your own tools, schedule daily scans, or pipe output to Telegram.

curl https://your-agent.railway.app/research/PLTR \
  -H "X-Agent-Key: your-secret" \
  | jq .
import requests

r = requests.get(
    "https://your-agent.railway.app/research/PLTR",
    headers={"X-Agent-Key": "your-secret"}
)
print(r.text)
const res = await fetch(
  "https://your-agent.railway.app/research/PLTR",
  { headers: { "X-Agent-Key": "your-secret" } }
);
console.log(await res.text());
